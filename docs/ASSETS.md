# Registro de assets

## En uso

Mapa, materiales planos, luminarias y representación provisional: geometría creada para este proyecto. No se han descargado ni incorporado modelos de personajes de terceros en esta versión inicial.

The Locust, Sunman, The Boiled One y Guilt se incluyen en el concepto de The Four a petición del usuario, dentro del universo de Doctor Nowhere. La licencia de un modelo de un fan no acredita por sí sola los derechos del personaje original.
