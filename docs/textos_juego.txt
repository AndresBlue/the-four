THE FOUR — TEXTOS VISIBLES DEL JUEGO
=====================================

Cómo usar este archivo
----------------------
- Cada entrada tiene un identificador entre corchetes, dónde aparece y el texto ACTUAL.
- Escribe tu versión en la línea CORRECCIÓN. Si la dejas vacía, el texto se mantiene.
- Escribe "eliminar" en CORRECCIÓN para quitar ese texto, o debajo del título de una
  sección para quitar la sección completa.
- Las líneas que empiezan por "| " son saltos de línea dentro del mismo texto.
- %s, %d o [TECLA] se sustituyen en el juego por un valor (tecla, número, fecha...).
  Mantenlos donde quieras que aparezca ese valor.
- "OBS:" es una observación mía sobre textos que pueden sonar artificiales o
  redundantes. Ignórala si no estás de acuerdo.

CORRECCIÓN:

[ERR.02] Checkpoint de otra versión
ACTUAL: Checkpoint incompatible con esta versión. Se conserva el archivo original.
CORRECCIÓN:

[ERR.03] Checkpoint con datos incorrectos
ACTUAL: El checkpoint contiene una semilla inválida.
CORRECCIÓN:

[ERR.04] No se pudo escribir el guardado
ACTUAL: No se pudo guardar el inicio del piso.
CORRECCIÓN:

[ERR.05] Falla el mapa de respaldo
ACTUAL: El mapa de respaldo no superó la validación física. No se inició la partida.
CORRECCIÓN:

[ERR.06] No hay ruta hasta la salida
ACTUAL: No se pudo validar la ruta de salida. El nivel no se inició.
